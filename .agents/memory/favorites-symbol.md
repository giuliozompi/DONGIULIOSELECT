name: Website favorites symbol
description: Product-specific visual instruction for the website favorites control.
---

Use a selectable yellow cheese slice with holes for website favorites, not a heart.

**Why:** The user explicitly requested “al posto del cuoricino aggiungiamo la fetta di formaggio con i buchi gialla selezionabile”.

**How to apply:** Keep the symbol consistent across product selection controls, favorites navigation and the favorites page, with a visible distinction between selected and unselected.
